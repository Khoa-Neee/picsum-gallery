404 – Trang không tồn tại

Đường dẫn bạn truy cập không tìm thấy. Nếu bạn đang mở trực tiếp một đường dẫn sâu (ví dụ /photos/123) trên GitHub Pages, hãy cấu hình bước build sao chép dist/index.html thành dist/404.html để React Router xử lý đúng.

Quay lại ứng dụng: Về trang chủ

Mẹo: cập nhật script deploy trong package.json thành:
"deploy": "npm run build && node -e \"require('fs').copyFileSync('dist/index.html','dist/404.html')\" && gh-pages -d dist"
